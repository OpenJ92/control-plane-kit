This is the composition witness for authoring topology -> compiled graph ->
codec -> validation -> diff -> activity plan. Pure materialization fixtures
teach environment socket wiring, exact protocols, activated socket-bound secret
deliveries and absent-edge delivery inactivity.

Initial deployment yields typed runtime/node/health activities; environment
wiring does not require a separate runtime-control connection command. A
runtime-controlled router edge switch instead becomes an explicit switch
activity without generic node reconciliation. The Recipe/compile_recipe names
remain aliases of the same current topology/compiler identities.

These tests demonstrate the interpreter-oriented shape across pure owners.
They do not start Docker, resolve custody, authorize a plan or prove that a
running router changed its target. Begin with
[algebra.py](../src/control_plane_kit_core/algebra.py.md) and
[topology/compiler.py](../src/control_plane_kit_core/topology/compiler.py.md);
