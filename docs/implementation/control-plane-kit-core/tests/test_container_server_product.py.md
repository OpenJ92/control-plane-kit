Six tests cover the pure ContainerServerProduct value and its variant codec in [products.py](../../../../control-plane-kit-core/src/control_plane_kit_core/products.py). The helper combines a namespaced product identity, digest-pinned image with a display tag, one HTTP provider socket and descriptive text. Construction assertions check the identity key, exact image execution reference and provider names. They do not start a proxy, verify registry content, select a runtime or bind a network port.

The immutability/hashability test constructs sets containing the same fixture product and rejects assigning a new display_name with FrozenInstanceError. This establishes hashability and ordinary frozen-field assignment rejection for that example. It does not test independent equal instances, every nested runtime-contract variant, deep immutability, bypasses of dataclass freezing or stable hashes across processes. A Python hash is not the durable descriptor digest described in [the product-reference tests](test_product_reference.py.md).

The codec round-trip checks the container-server discriminator, reconstructed value equality and identical re-encoding. The unknown-kind case preserves the rest of the valid descriptor and expects an unsupported-variant error; a separate extra python_class field must also fail. Unlike the incomplete replacement in the document-codec tests, this kind case isolates the discriminator change. Missing fields, wrong primitive types, product-family variants and all nested rejection paths are not tested here. The actual codec requires exact product keys and delegates identity, image and runtime-contract decoding to their owners; nested failures may be wrapped with their cause retained.

Two metadata examples reject a Docker socket path in display_name and backtick-shaped command text in description. The source validator applies 128/1024-character limits, nonempty-text/NUL checks and a finite forbidden-fragment list. Despite the test's bounded-metadata name, neither example probes a length boundary. The file does not prove universal shell/path safety, redaction or an operator registry policy. These fields remain descriptive values rather than executable commands.

The final test parses all of products.py. It rejects eight named import roots and ten forbidden names found in annotated assignments whose target is a plain name. This scan includes matching annotations beyond ContainerServerProduct fields; it does not inspect every function argument, unannotated assignment, mapping key, attribute assignment or dynamic execution path. Absence of those spellings is a finite source constraint, not proof that callbacks or effects cannot be hidden through other syntax.
