RuntimeRecord stores one optional keyword-only RuntimeManagement value. Node
stores gateway transit only through BlockSpec, with no duplicate field. Public
descriptors preserve present declarations and omit absence so legacy graph bytes
remain unchanged. These are references and advertisements, never executable
authority or observations. Canonical relationship rules are owned by codec.py;
the health selector is documented in validation.py.md.
