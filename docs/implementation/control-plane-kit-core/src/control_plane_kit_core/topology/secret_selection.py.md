evidence, never registration or current authority. The declaration-only relation
preserves product family/image, exact installed V2 receiver identity/verifiers,
the existing readiness-bearing health relation, restored node equality and secret
delivery/selection laws.

Equal required receiver slots may carry across that relation when complete
contracts agree after restoring only the allowed control-surface difference.
Required declarations have no payload to decode. Mixed required/concrete pairs
refuse in either direction. Concrete pairs retain their existing opaque/inert
default behavior and, when changed, their own payload identity/trust checks.
Operations remains responsible for registration, current trust and admission.
