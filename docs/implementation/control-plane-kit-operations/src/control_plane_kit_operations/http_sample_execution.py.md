The immutable support descriptor names the installed gateway product/slots/pure
decoder and public transit socket. RuntimeAdapterRegistration separately checks
that the same descriptor is consumed by its actual native adapter. The route
reader reloads the original plan projections and exact registered products,
reuses the existing compatibility owner, and selects the runtime's named HTTPS
ingress targeting that gateway/socket. The returned route and prepared-check
values contain only public/reference metadata. They do not establish authority,
sign, resolve secrets or make provider calls. ExecutionInvocationService owns
acquisition state, current admission, physical commit and truthful history.
