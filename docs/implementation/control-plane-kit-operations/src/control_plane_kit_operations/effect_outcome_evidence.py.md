This owner binds typed effect outcomes to their immutable original intent,
request and recorded plan, preserving bounded evidence and uncertainty. The
original-observation-plan check recognizes both managed-update-v1 and
retained-image-ingress-v1 as requiring independent managed replacement evidence.
It does not select a new plan, reinterpret a V1 record, grant current authority or
infer installation from readiness. Existing exact source, session, operation and
request correspondence checks remain unchanged.

Native acceptance retains its original sample and acceptance reason; successful
connection, signed management path, public readiness, replacement/configuration
receipt and protected workload health remain separate facts. No new provider,
credential, network, database schema or retry surface is added by the profile.
