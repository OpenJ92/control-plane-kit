This private store owns immutable intent-preimage rows on the caller's Postgres connection. It exposes exact insert/get through the store bundle, not a public query API. [EffectAttemptIntentRecord](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/effect_attempt_intent_evidence.py) owns value/canonical admission; [effect_attempt_start_interpreter.py](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/effect_attempt_start_interpreter.py) owns authority, transaction and replay decisions.

Insert revalidates the record and performs a parameterized insert without upsert or commit. Get selects one exact run/activity/attempt key, joins the original event, bounds preimage retrieval to 1 MiB and validates the stored row's duplicated coordinates against the decoded record. Missing evidence is distinct from invalid evidence. Unexpected driver faults remain faults, not fabricated misses.

There is no workspace/actor argument or authorization check in this store. Its exact-key lookup is not an access grant. Callers must establish scope before reading, and must not publish the protected preimage merely because the join validates. It does not lock a row for mutation, resolve secrets, call a provider, repair history or recreate transient grants.

The private current-schema validator scans bounded keyset batches and checks orphan/mismatched attempt associations. This is schema admission, not broad operator inspection or an excuse to silently repair retained data. Preserve caller-owned transaction/rollback semantics.
