This generic owner publishes pre-derived immutable realized material for an unchanged authored graph, updates only the desired projection/generation and appends a publication action. “Realized” names executable graph material, not a provider observation or successful deployment. The service does not derive rotation material, approve a plan, advance current graph, execute effects, revoke keys or change provider state.

PublishDesiredRealizedProjection carries session/workspace/actor, expected authored/projection/generation, a typed projection, source operation ID/version and idempotency key. It checks nonblank text, exact nonnegative generation/positive source version, projection type and workspace/authored ownership. Its local text checks are not size/control/redaction limits, and numeric checks do not enforce database maxima. The imported projection record verifies canonical graph representation and a material digest; that does not prove provider state or source-operation authorization. The command descriptor fingerprints coordinates, projection digest/kind/key and source operation, not an embedded graph body.

DesiredRealizedProjectionCommandService allocates clock/action ID before calling the in-UoW helper and commits its result. Thus replay avoids durable mutation but does not avoid these outer factory calls. The helper itself never commits. It locks session/action idempotency, fingerprints intent and resolves matching existing action before fresh session/workspace/pointer checks. Fresh admission requires an open same-workspace session and the exact current desired authored/projection/generation tuple under workspace lock. It saves immutable projection material, performs SQL compare-and-set on that tuple, increments generation and appends coordinate/source-operation action evidence in one transaction. A caller rollback must cover all prior writes if any later step fails.

Replay requires the publication action kind/fingerprint, string evidence fields, positive exact generation, retained projection existence and matching digest, then returns the historical result with replayed=true. Result construction crosschecks six result fields against action payload, not an exact closed payload schema. This is not a full revalidation of every action field, source-operation row, current pointer, session state or projection-to-action coordinate relation under arbitrary database corruption. It never reapplies a historical desired pointer. Cryptographic hashing here detects material inconsistency, not approval or an adversary able to rewrite coordinated records.

prepare_desired_realized_projection_publication is only an early key/session fence: an existing action is returned without kind/fingerprint verification, while new work locks an open session. Callers must still invoke the full publication path. Selected gateway overlap/retirement callers check delegation-key.rotate scope, derive their phase-specific material and use these helpers in their surrounding transaction. This generic service has no scopes/principal or source-operation lookup; neither helper alone supplies those callers' rotation authority or phase laws.

Projection-save ValueError is converted using str(error) with an explicit cause; other lookup errors also chain. Arbitrary identifiers, keys, source coordinates and exceptions are not universally redacted or bounded here. Stored action excludes the graph body but is not safe for indiscriminate public logging. Full 384-line owner read; selected actual projection/graph record constructors, immutable save and desired CAS SQL, and both overlap/retirement integration call sites checked. No full rotation caller/test/store audit or executable/provider action. Documentation grants no autonomous publication, recovery or cleanup authority.
