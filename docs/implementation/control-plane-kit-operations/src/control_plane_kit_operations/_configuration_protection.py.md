The private frozen protective allocation separates an independently proven exact
birth from an ordered unique set of zero to 64 matching direct-root claims.
It has no export, codec, effect or permission. D2A retains every claim, including
the birth; empty is only a representable value for the later closure reader.
The public historical allocation still requires one to 64 claims and its birth
inside that complete set. The preparation owner supplies the actual proof.
