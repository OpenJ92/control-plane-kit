This package-private function admits the canonical UTC text used by durable records. It accepts only exact str, not subclasses, then requires UTF-8 encoding within 27 bytes and an ASCII calendar/time shape ending in Z. The shape allows either whole seconds or six fractional digits; parsing and rendering then enforce an actual date and canonical spelling. Nonzero microseconds retain six digits, while a whole-second instant must omit the fraction: .000000Z is not a valid record timestamp even though the cursor language uses it.

Successful validation returns the original string unchanged. Offset aliases, variable fractions, invalid dates, leap-second spelling, trailing material and other noncanonical forms are not normalized into acceptance. Calendar parsing rejects shapes such as an impossible day that the initial regex alone would admit. The function does not read a clock, compare chronology or freshness, or convert user-local time; those are caller concerns.

Expected type, encoding, shape and calendar failures raise the same fixed ValueError without interpolating rejected material. Parsing/encoding catches set local failure flags and raise outside their handlers rather than attaching raw parse errors. This is bounded format admission, not authentication or a general secret scrubber; it performs no persistence or effects and has no public exports in __all__.
