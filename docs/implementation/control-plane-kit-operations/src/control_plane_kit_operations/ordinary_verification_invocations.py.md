#2089 accepts a nonempty all-HTTP set or one supported authenticated SQL check
on a registered local Docker authority. Other/mixed/empty sets and remote SQL
refuse. SQL counts three reached roles, check and acquisition, with no eager
password reference use. The new acquisition domain is separate; old fingerprints
remain literal. Product and physical qualification are independent owner facts.

Original recorded sample plans derive a distinct acquisition target and two
dynamic signing-resolution slots per original HTTP check. This public sample
arm does not connect to Docker and declares no unused private TLS roles.
Ordinary Docker profiles retain their prior target recipe and TLS/password
roles. The profile and family bound are immutable history descriptions, not
current authority or evidence that a runtime consumes the supplied capability.
