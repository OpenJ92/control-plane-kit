This internal pure calculation joins already loaded owner records. It pins plan,
workspace, authored graph IDs and projection IDs, reproduces the recorded Core
interpretation, and reuses registered product equality and Core receiver/sample
binding. The expected sample slot is selected from registered descriptor facts
before graph material. Receiver routing uses its named registered HTTP port;
each original check retains its own independently registered local port.
The product-qualified binding supplies a required independent route slot as well
as the trust slot. Registered and authored artifacts must match each expected
ID/path/media/mode before decoding; their agreement with each other is insufficient.
No production gateway path is embedded or inferred by Operations. Issuer and alias
reuse Core sample reference validation, each key ID uses its identifier validation,
and an accepted alias is preserved exactly. Core-valid long issuers remain valid.

Gateway public trust must come from an explicitly bound product/slot decoder and
match the sample transit purpose and independent V2 gateway target. The decoder
is a pure public-material parser, not a signer or transport. Compatibility is
neither current permission nor evidence of installed configuration or responses.
No stores, credentials, provider or network handles are accepted; no durable
receipt or executable authority is created. Both execution denials stay closed.
Consumers must load owner records and enforce current admission separately.
