original request/run/attempt/outcome reads. The active route uses existing
bounded store decoders. The observer runs outside a database transaction, and
fresh outcome folding acquires its own lifecycle-first transaction prefix.

OBSERVE / #2049 resolves exactly one immutable original: the genuine prepared
invocation, or the new registered-local unprepared selection. It validates the
unchanged original execution profile before projecting observation-only roles.
Passive observation uses only remote TLS connection credentials, or none for
local reads. Pull credentials, consumer selections and probe passwords are not
observation roles. A fresh command supplies current permission and acknowledged
invocation admission; original provenance does not grant permission. R target
bytes remain unchanged. New targets commit the tagged original invocation ID or
full origin fingerprint, so distinct original attempts cannot alias.
