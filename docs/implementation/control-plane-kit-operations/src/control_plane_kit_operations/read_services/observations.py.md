This owner interprets immutable observation records at a read instant; it neither probes providers nor changes graph or observation truth. The private projection requires the workspace, samples its injected clock once, checks for a datetime with timezone information, then requests the latest-observations page. The optional store is checked after the clock. Authorization belongs outside this projection; workspace existence alone is not permission.

Freshness follows explicit precedence: recorded stale, missing graph correlation, changed current graph, malformed/naive observation timestamp, future timestamp, then expiry. The default maximum age is five minutes and must be positive; exactly the maximum age remains fresh. Ordinary aware timestamps are compared in UTC. The returned ProjectedObservation retains the original record object; the read descriptor is constructed with derived freshness fields and a redacted payload. A healthy status can therefore remain healthy-looking but stale; fresh evidence is not a new health check or proof that external state has not changed.

The caller owns transaction/snapshot consistency. This module does not lock the workspace and observations together or establish one database snapshot. The actual Postgres store selects the newest row per subject using observed_at then observation_id, and pages subjects in ascending identity order; the projection trusts that store contract rather than selecting rows itself. ReadPage.map preserves request and cursor and maps only exposed items, so freshness applies to the returned page, not an exhaustive provider inventory.

Typed ObservationRecord and BoundedEvidence supply upstream shape/correlation and encoded-evidence limits. Only the payload passes through the shared key-based redactor; public identifiers and timestamps remain visible. That helper is not content-based secret detection. The direct project_observation function assumes typed records, policy and datetime values; neither it nor the store path is a universal hostile-object boundary. Fixed clock/store-absence errors avoid interpolating those objects, but workspace, clock, store or unexpected descriptor failures otherwise propagate without general sanitization.
