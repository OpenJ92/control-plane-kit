This private family projects stored runtime authorities, process-access deliveries, ingress authorities, secret-provider registrations and secret-reference registrations. Each call checks workspace existence before its independently optional store. That callback is not principal authorization; the outer command/read boundary and caller-owned UoW supply authority and transaction context. No provider, credential file, mutation or secret-resolution capability is called here.

Collections delegate to `active_page(request)` and map its values without rebuilding pagination. Detail lookup contracts differ: runtime/delivery/ingress use `get`, provider uses `get_active`, reference uses `get_by_registration`. The current Postgres authority getters prefer active records but may return historical nonactive records; reference registration detail is not active-only. Do not infer execution permission from a detail or rename all these reads as active-authority admission.

Runtime/delivery/ingress records need a callable descriptor returning a Mapping, then pass through the shared key-based redactor. Secret-provider/reference records instead require their registered types and return their descriptors directly. Those descriptors deliberately expose opaque endpoint/credential/reference handles, allowed scopes, provenance and metadata, not resolved credentials. These are different public contracts, not one universal sanitizer. See [secret_providers.py](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/secret_providers.py) and [_redaction.py](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/_redaction.py).

Selected missing-record exceptions become `ReadModelError`; authority errors include the requested reference, while secret errors use fixed messages. Wrapped exceptions retain cause/context. Unexpected store/descriptor exceptions propagate; arbitrary descriptors are not fully type-, size- or content-validated here. Registration validation and the outer response boundary remain consequential dependencies.

[InstanceReadService](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/instance.py) delegates this family. The [focused tests](../../../../../../control-plane-kit-operations/tests/test_authority_secret_read_projection.py) cover optional capability isolation, projection/error seams and existing module partition; store query filtering is owned by [runtime stores](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/postgres/runtime_authority_store.py), [ingress store](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/postgres/ingress_authority_store.py) and [secret stores](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/postgres/secret_provider_store.py). These reads report durable CPK truth, not fresh provider possession or health.
