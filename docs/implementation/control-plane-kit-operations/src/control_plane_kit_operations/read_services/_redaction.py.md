This private helper recursively projects descriptor values using key-based heuristics. Keys are lowercased and hyphens normalized for sensitive matching: secret/token/password/private-key/credential/api-key markers, exact address/url/environment/env-assignments names, and non-dotted `_url` suffixes become `<redacted>`. It does not inspect arbitrary string values for secrets or addresses. Safe-looking keys can therefore carry unsafe content; callers must supply the right descriptor shape.

`environment_bindings` takes a special branch before general matching. A list or tuple is projected to a list; non-mapping entries are redacted. Exact child keys `value`, `reference`, and `reference_id` are redacted; other keys recurse through the ordinary rules. This preserves structural binding metadata without returning those value/reference slots. Ordinary mappings are sorted and stringified by key, lists recurse, tuples remain tuples, and other values pass through unchanged.

There is no depth/byte bound, cycle handling, general JSON validation or exception normalization. Mixed incomparable mapping keys can fail sorting, and arbitrary non-container values are returned unchanged. This is not a universal sanitizer or safe serialization boundary. It neither changes source records nor resolves secrets or contacts a provider.
