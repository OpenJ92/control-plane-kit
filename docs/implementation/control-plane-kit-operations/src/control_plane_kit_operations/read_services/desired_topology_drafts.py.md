This private projection reads saved desired intent; it does not select a draft, prepare a deployment, approve work, or execute effects. InstanceReadService supplies workspace admission, graph storage, the optional draft store and optional revision-history store. Workspace existence is checked for both page and detail reads; actor authorization belongs to the surrounding service, not this projection.

Page requests carry the closed collection/scope/limit/cursor contract from ReadPageRequest. Revision-list reads additionally require the parent draft through store.get; missing parents become fixed ReadModelError("missing draft"). The store owns membership and pagination. Mapping each exposed record to its descriptor preserves the page's request and cursor rather than rebuilding pagination here. A missing draft store raises the fixed catalogue-unavailable error; unrelated store failures are not universally sanitized by this module.

Detail reads resolve the exact revision and its stored graph, normalize missing records to "missing draft revision", and reject a graph belonging to another workspace. The Core graph codec and graph validation run before descriptor projection. The returned FocusedDetailReadModel contains the revision record descriptor, a redacted graph descriptor and revision-history presence. History is required for this detail shape: an absent history store fails rather than inventing empty history. No current-graph selection or provider observation occurs.

Graph redaction delegates to the shared recursive key-based helper: sensitive keys and environment binding values/references are suppressed. It is not arbitrary-content secret detection. The revision record's public coordinates, creator and creation time remain visible. History presence describes recorded source/target associations only, not completed deployment, current health or authority to retry. The caller owns database transaction/snapshot consistency; this projection does not combine its separate store calls into a new snapshot or commit.
