These internal `typing.Protocol` declarations describe store capabilities consumed by read projections: workspace/graphs, sessions/actions/plans/approvals, execution runs/events/receipts, observations, authority/delivery metadata, registered secret providers/references, gateway probes, signing keys and saved-preparation source correlation. They are not runtime-checkable adapters and contain no queries, writes, commits, provider calls or authorization implementation.

Some signatures return concrete Operations records; others intentionally return `object`. Likewise tuple-returning lists and overview lookups are not inherently bounded by the protocol. Paged methods consume the existing [ReadPageRequest/ReadPage](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_pages.py) contract; its collection/scope/cursor and limit checks belong there and in the concrete store. A type declaration does not prove an implementation honors them, uses one snapshot or checks workspace ownership.

Core supplies reference/purpose values; Operations supplies durable records, registration values and pagination. Secret registration reads are not secret resolution. The [instance service](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/instance.py) accepts these capabilities and delegates to projection families; other families also have contracts defined in their own modules, so this file is not an exhaustive store inventory. Do not publish internal protocol names through the facade merely to mirror source organization.

Full declarations read with selected current instance wiring and page-value contracts.
