This private family projects gateway attempt history, signing-key inventory and public verifier configuration. Workspace existence precedes optional store access; it is not caller authorization. Probe reads work without a signing-key store and key reads without a probe store. No signature, provider probe, rotation, key resolution or deployment happens here.

Probe pages map stored attempt descriptors. Detail fetches by probe ID and explicitly hides a foreign-workspace result behind the same cause-free missing error as `KeyError`. The attempted request/grant coordinates, durable status and bounded evidence come from [GatewayProbeAttempt](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/gateway_probes.py), not a fresh probe. Descriptor failures and malformed records can still raise raw exceptions; this family is not universal error normalization.

Key inventory selects explicit public lifecycle/provenance fields and omits the private-key reference and PEM. Verifier detail intentionally includes public PEM and process environment bindings. It requests one unambiguous active gateway-probe key, then verification keys for that workspace/purpose/issuer and requires an active member. The current [Postgres store](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/postgres/delegation_signing_key_store.py) owns active selection, shared purpose locking and active/verify-only filtering; the caller owns transaction lifetime. The configuration value sorts unique key IDs and bounds the set at sixteen. The projection does not independently revalidate every store relation or resolve a gateway node in the current graph.

Audience is derived as `gateway:<workspace>:<node>` from the supplied coordinate. Public configuration is a deployable value, not proof that a gateway installed it, rejected replay, or possesses the named key. Selected key/configuration failures become one fixed public message but retain cause/context; unrecognized errors are not swallowed. Do not treat fixed text as universal traceback redaction.

[InstanceReadService](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/instance.py) is the public facade. The [focused tests](../../../../../../control-plane-kit-operations/tests/test_gateway_security_read_projection.py) use fake stores and public-key fixtures to protect projection/capability boundaries, not cryptographic or live-gateway acceptance.
