Two frozen dataclasses carry already-projected values. `OperatorOverviewReadModel.descriptor()` supplies workspace/kind plus shallow copies of graphs, workflow, history and next-action mappings. `FocusedDetailReadModel.descriptor()` supplies workspace/kind followed by an expanded payload. Payload keys can override those two detail envelope keys; this constructor does not reserve them or validate callers' mappings.

Neither class has `__post_init__` validation, recursive copying, bounds, redaction, authorization or store reads. Frozen attributes do not make nested mappings immutable. The overview docstring describes intended producer discipline, not a guarantee enforced by these containers. [operator_overview.py](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/operator_overview.py) owns its correlated/fail-closed assembly; detail families such as [desired_topology_drafts.py](../../../../../../control-plane-kit-operations/src/control_plane_kit_operations/read_services/desired_topology_drafts.py) own their workspace and payload checks. Never pass raw provider data to a model and rely on `descriptor()` to sanitize it.
