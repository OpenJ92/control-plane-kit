This owner projects workspace records and their stored graph references into WorkspaceSummary, GraphPointerReadModel, WorkspaceReadModel and ControlSurfaceReadModel. These frozen dataclasses are read containers, not independent validators or deeply immutable snapshots: nested mappings remain caller-supplied and descriptor copies are shallow except where the projection explicitly redacts. The store/caller supplies typed durable truth; actor authorization and transaction consistency are outside this module.

Workspace/current/desired reads require an existing workspace, then follow its graph/projection IDs. A normal graph pointer is unassigned if either ID is absent; an assigned result exposes the stored authored graph and referenced realized-projection ID, without loading or validating the realized projection itself. The graph lookup checks existence but does not independently compare its workspace to the requested workspace. Preserve the durable pointer/store ownership invariants and outer authorization when composing this projection; it is not a substitute for them.

Ordinary graph-pointer reads redact the stored descriptor without decoding it. operator_graph instead decodes and validates it with the configured Core codec, then builds deterministic sorted runtime/node/socket/edge views. Connected flags reflect declared edges, not successful network connections. Display names, socket names and environment-binding names are public structural fields; metadata uses the shared key-based redactor. No provider, runtime endpoint or variable-state query is made.

control_surface accepts only current/desired pointers, follows the authored graph ID (not the normal pointer's two-ID assigned test), decodes/validates/re-encodes the graph, redacts it and projects static node declarations. Providers, requirements, capabilities and block-spec control surfaces are declarations, not proof that a server is running or a control command is authorized. The empty warnings list is an output shape, not an operational health certificate.

Missing graph truth and expected decode/validation failures have fixed read errors; missing workspace text includes the requested identifier. Other store/custom-codec failures are not universally caught. Redaction suppresses configured sensitive keys and environment values/references; it is not arbitrary-content scanning. Graph names/display names and other public structural strings must remain appropriate at their producers. This module commits nothing, changes no pointers and performs no recovery or provider action.
