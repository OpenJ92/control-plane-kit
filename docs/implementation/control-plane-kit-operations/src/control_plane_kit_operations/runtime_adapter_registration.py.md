#2089's optional managed support must be the exact object consumed by the
registered native adapter, whose HTTP arm shares the nested sample support.
Copies/descriptors are insufficient. Old registrations default to absent.
This declaration proves no physical execution behavior.

The optional sample support is explicitly typed and defaults to absent. Its
qualification requires the semantic invocation profile, ordinary per-check port,
and identity equality with the same descriptor on the actual native adapter.
An equivalent copied descriptor is not the installed consumer. This predicate
is checked again by the sample invocation owner; it does not infer native
conformance or public deployment qualification from a boolean declaration.
