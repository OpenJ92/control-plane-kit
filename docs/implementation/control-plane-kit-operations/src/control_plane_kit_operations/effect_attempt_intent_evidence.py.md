This owner binds the Core pre-start intent to the exact attempt identity and original start event. Its private canonical codec provides a durable preimage, not a provider observation or an executable request archive. [effect_attempt_intent_store.py](../../../../../control-plane-kit-operations/src/control_plane_kit_operations/postgres/effect_attempt_intent_store.py) persists it; [effect_attempt_start_interpreter.py](../../../../../control-plane-kit-operations/src/control_plane_kit_operations/effect_attempt_start_interpreter.py) establishes the transactional association.

The important information boundary is Core's [RuntimeEffectIntent projection](../../../../../control-plane-kit-core/src/control_plane_kit_core/runtime_effect_observation.py): generated effect/start-event identity and transient secret-resolution grants are omitted. Authority references, delivery descriptors and product material remain. Consequently the preimage may contain private addresses and secret references even though it contains neither resolved secret values nor grants. Do not send it through ordinary public reports or treat its fingerprint as permission to resolve or dispatch.

Admission reconstructs exact values, checks identity/event/intent correlation, and requires the private canonical round trip. The validation-only request uses a synthetic event identity and empty grants; that is a structural check, not a dispatch. Hash equality alone does not admit forged values. Both forward and compensation start events are representable; operation polarity is not inferred from the event name.

The codec requires bounded canonical RFC 8785 bytes and rejects duplicate keys, noncanonical documents and malformed components. Known contract failures become the fixed Operations record error; do not broaden that into swallowing unexpected failures. The record hides intent/event in its repr, which is not an authorization boundary.

Tests: [test_effect_attempt_intent_contract.py](../../../../../control-plane-kit-operations/tests/test_effect_attempt_intent_contract.py) distinguishes protected preimage from generated data, exact value/codec admission and event-coordinate correlation. These are Operations persistence-input laws; Core remains the projection owner. A successful round trip proves neither current provider state nor retry safety.
