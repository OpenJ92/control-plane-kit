Pure typed commands and references describe resumable deployment intent.
Preparation accepts an optional `proposed_graph_id` only with an inline graph.
The shared graph-authoring validator applies Core's public graph-revision name
law; invalid input becomes a fixed detached contract error. Saved revisions
already possess immutable identity and cannot accept a replacement proposal.
The optional field appears in descriptors only when supplied, preserving the
historical omitted shape. Validation performs no IO or authority allocation.
Contract tests retain all prior field, import, redaction and effect boundaries;
the preparation suite owns durable inline propagation and saved-mode refusal.
