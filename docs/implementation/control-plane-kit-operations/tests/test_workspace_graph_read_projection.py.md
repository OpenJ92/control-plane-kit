Three test methods protect the workspace/graph projection split, a shared workspace lookup and categorical graph failures. Stores are small in-memory doubles holding typed records; the graph codecs either reject with a hostile diagnostic or return a graph with a missing child. RuntimeKind.DOCKER is graph data here, not a Docker client or provider action. There is no database fixture in this owner.

The first method checks five public facade signatures, including keyword-only pointer defaults, then parses the actual facade source. It requires each selected method to return a call through _workspace_graph, excludes an old _workspace helper, and checks that four other projection families receive _workspace_graph.require_workspace as their first constructor argument. This is a deliberately structural extraction contract, not proof of every argument's runtime dataflow or an exhaustive census of newer projection families.

The second method calls session_detail through the actual facade with a typed session and records exactly one workspace lookup. It provides one behavioral composition witness alongside the AST checks; it does not establish authorization or transaction isolation.

The final method has eight cases across operator_graph/control_surface: unknown pointer, missing graph, rejected decoding and invalid decoded graph. Each must raise exactly ReadModelError with the expected fixed text, bounded repr and no cause/context; the chosen hostile candidate must be absent from both representations. Catching BaseException in the test collects any outcome for an exact-type assertion; it is not a production rule to swallow cancellation. These cases establish categorical failures for those boundaries, not universal content redaction or all possible store/codec failures.

Full 299-line test owner read against the fully read [facade](../src/control_plane_kit_operations/read_services/instance.py.md) and [workspace graph projection](../src/control_plane_kit_operations/read_services/workspace_graph.py.md). Core graph validation remains Core-owned; the malformed graph exercises composition with that validator. No test execution, live HTTP/MCP, Docker or provider evidence is claimed; executable validation belongs to the existing Docker-backed Operations suite.
