This shared fixture constructs synthetic database rows for [collection paging](test_large_read_collection_pages.py.md) and [HTTP/MCP-shaped route parity](test_large_read_route_parity.py.md). It is setup, not an assertion owner or an account of executed deployment history. Both consumers currently request 201 selected rows; their own helpers additionally seed catalogue/revision collections. No tests or database operations were run for this note.

`seed_large_read_history` accepts a caller-owned connection and an exact positive integer count, default 201. Booleans and nonpositive values fail admission; there is no upper count bound. Frozen slotted handles return the fixed workspace and parent identities used by consumers, without validating authority or correlating provider resources. Workspace IDs are collected from handle fields ending in workspace_id and inserted with running lifecycle. SQL generate_series and padded numeric suffixes make repeatable finite datasets, not globally fresh identities or an idempotent seed operation. Reusing the same populated schema can collide.

The fixture does not open a connection, install schema, select search_path, establish an encompassing transaction, commit, roll back or clean up. Those responsibilities stay with the consumer. Its writes follow the supplied connection's transaction mode; a later failure need not undo earlier committed statements on an autocommit connection. Consumer tests create isolated schemas, but this helper itself does not prove that the supplied database is disposable.

Most rows use direct SQL rather than command admission. Open sessions and ordinal actions populate independent workspaces. Plans use an encoded empty ActivityPlan and authored/identity-realized graph pairs created through the [graph-lineage helper](../../../../control-plane-kit-operations/tests/graph_lineage_fixture.py) and PostgresStoreBundle. Approval subjects and review digests are generated without invoking approval policy. Pending approvals lack decisions. Run fixtures directly combine approved decisions, cancelled execution requests and succeeded runs, with fixed timestamps. Event fixtures append repeated run_started events to a seeded succeeded run. These combinations are deliberate read data, not evidence of a valid lifecycle trace, authorization, execution, effects or graph convergence.

Current-metadata datasets include healthy/fresh observations, local Docker authorities and delivery records, Cloudflare ingress authority rows, secret providers and references. Their statuses, invalid.test endpoints, opaque secret references and IDs are synthetic values. Delivery rows do not establish a matching admitted authority in that separate workspace; ingress/provider references are likewise not proof of admitted cross-owner relationships or credential custody. The reference dataset supplies its own synthetic parent provider. No registry command, secret resolver, socket, HTTP endpoint or provider is consulted. Read projections and consumer assertions, not this setup, own which fields may appear publicly.

Delegation-key rows use deterministic registration hashes, gateway-probe purpose, verify-only status and a fixed PEM-shaped value. Hashing that literal does not prove a generated keypair, private-key possession or provider registration. Probe rows reference an empty identity graph, synthetic gateway/runtime/target and signing coordinates, fixed epoch/expiry values, an intended status and empty evidence. They are neither issued grants nor signed requests, dispatched probes, observed health or verified responses.

The common fixed instant and identities support ordering/cardinality comparisons. They do not model elapsed time, concurrent writers, bounded work at arbitrary scale, a consistent multi-page snapshot or actual provider truth. Tests may replace selected rows between reads; those changes belong to the consuming test's law, not an implicit fixture guarantee. Keep schema-driven seed changes coordinated with both consumers, especially if lifecycle, foreign-key, identity or public-redaction contracts change.
