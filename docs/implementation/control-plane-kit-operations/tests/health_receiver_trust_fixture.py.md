The fixture builds real management graphs, registered product descriptors and selected configuration artifacts before the existing compiler/registration services run. Workload own-health uses the shared Core wire format plus CPK_WRAPPER_CONFIGURATION_FILE. Gateway transit retains a distinct test-only byte format/decoder; its binding list contains transit only. The workload_trust helper constructs public fact values for their nominal-value tests, not an application decoder port.

Descriptor defaults deliberately contain a different key from actual selected bytes. Malformed profile/purpose/key/identity changes stay literal selected artifact data so owner refusals, rather than fixture constructors, expose the negative law. Separate gateway bootstrap contexts put transit and common own-health on one product. A pre-compilation transform supports independently named/located registered products and the A-to-B redirection witness. Graph compilation, first-start, authority reload, transaction state and history are never reimplemented here.

The original Operations1872 causal-red checkpoint opted into shared bytes while leaving predecessor fixtures unchanged. The migration then makes shared own-health the default and removes the test decoder's own-health interpretation. Public keys are synthetic; no signing/private material or provider effects occur. This fixture is package evidence, not Servers delivery or SDK transport acceptance.
