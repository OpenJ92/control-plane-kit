This setup-only extension of [DraftCatalogueFixture](draft_catalogue_fixture.py.md) adds selection/deletion interface checks, typed command builders, an actual planning service and controlled transaction-observation seams. It uses the ancestor's real unique-schema Postgres fixture; no replacement persistence or planner is introduced. Public route/callable assertions establish interface presence, not provider or transport acceptance.

select_command reads workspace state and captures expected desired graph/projection/generation; delete_command carries expected draft head; plan_command captures current/desired lineage. dataclasses.replace allows tests to change selected inputs deliberately. restore_legacy_desired locks the workspace and performs the actual legacy desired-pointer update in a committed UoW: it mutates fixture state and is not a read helper or authorized operator recovery procedure.

_ObservedConnection delegates SQL to the real connection. It records normalized statement text, signals before a workspace SELECT FOR UPDATE attempt, executes the statement and optionally invokes an after-execute hook before returning its cursor. The signal means a lock was attempted, not acquired. Post-execute exceptions can therefore test rollback after a real write; they do not replace the write with a simulation. Other attributes delegate to the underlying connection.

observed_uow preserves schema-local connections and the ancestor's lock/statement timeouts. hold_clock exposes reached/release events and waits at most five seconds before raising; tests own coordinating and releasing it. This is a same-process timing seam, not a general scheduler, process kill or whole-suite timeout. truth combines the ancestor's selected table snapshots; effects excludes workspace/projection rows from runtime_truth, not every possible durable side effect or external resource.

Full 118-line fixture read alongside the full 212-line ancestor and [saved-preparation governing tests](test_saved_preparation.py.md), which use these lock/interruption seams. Actual saved admission/session transaction context was checked separately. No test/database/Docker/provider action was run; these helpers must execute only within the established Docker-backed package suite.
