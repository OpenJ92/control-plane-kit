Three real-Postgres tests protect native instant ordering and deterministic identity tie-breaks. Their key pair is a whole-second UTC timestamp and one microsecond later: lexical ordering of variable-fraction text would not be a safe substitute for ordering native temporal columns. Public record rendering must still return canonical UTC under non-UTC database sessions.

The schema test inserts sessions directly, checks database order, switches to America/New_York and reads them through the actual history store. The broader selector test uses Asia/Tokyo and checks ascending time/identity for sessions, plans, approval requests and runs; observation latest selects descending time/identity while observation history is ascending. Whole-second observation values must not acquire .000000Z in record output. Cursor spelling is a separate codec contract.

The authority test covers ingress registrations, runtime registrations and runtime access deliveries under Pacific/Honolulu. Within each owner, later native time wins among revoked rows, descending identity breaks equal-time ties, and an active older row outranks a newer revoked one. Store register/get calls are real persistence operations; copied/revoked rows are deliberately constructed through test SQL. Cloudflare authority values and Docker socket delivery declarations are stored fixture data, not provider clients, actual credential resolution or socket mounts.

Setup trusts CPK_OPERATIONS_TEST_DATABASE_URL, creates a unique UUID-derived schema and sets search_path. Each test installs the current schema. Normal teardown returns search_path to public, drops that exact schema with CASCADE and closes the connection. This is test-owned schema cleanup, not provider cleanup, and it is not a guarantee against all setup-failure residue. The owning Operations test.sh supplies disposable Docker isolation; the fixture does not verify the configured URL itself. No executable or database actions were performed for this note.
